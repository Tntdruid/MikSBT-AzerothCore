# Mik's Scrolling Battle Text for AzerothCore

Mik's Scrolling Battle Text is a World of Warcraft 3.3.5a addon that displays combat, loot, healing, damage, reputation, experience, and other battle information on screen.

## Compatibility

- World of Warcraft 3.3.5a
- Interface `30300`
- AzerothCore WotLK servers

## Installation

1. Download or clone this repository.
2. Copy the `MikScrollingBattleText` folder into your WoW `Interface/AddOns` directory.
3. Make sure the folder contains `MikScrollingBattleText.toc` directly.
4. Enable the addon from the character selection screen.

## Commands

Use `/msbt` in-game to open the addon options.
